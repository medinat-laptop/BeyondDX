# Project instructions

This is a locally run AICAPB 2026 event registration site. Keep changes focused on the user's request and preserve the existing React, Vite, and Tailwind conventions.

## Local development

- Install dependencies with `npm install`.
- Run the app with `npm run dev`.
- Run `npm run build` to verify production output.
- Registration entries are stored in browser local storage; do not imply that entries are sent to a server.
